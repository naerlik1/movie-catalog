Найден и исправлен случай отсутствия собственного отзыва: DRF `Response(None)` отдавал пустое тело с 200, а клиент ожидал JSON. Теперь endpoint возвращает 204, который клиент обрабатывает как отсутствие отзыва. Регрессионная проверка добавлена в тест владельцев отзывов.

В тестах используются отдельная PostgreSQL test-БД и временный каталог постеров. Тестовые данные не смешиваются с пользовательскими. Предупреждение WhiteNoise об отсутствии `staticfiles` появляется только при запуске из временного тестового контейнера без collectstatic; рабочий entrypoint собирает статику перед запуском gunicorn.

Исходники опубликованы на GitHub, образы — в личных публичных репозиториях Docker Hub; ссылки приведены в `PUBLICATION.md`. Пока не выполнены запуск на Ubuntu VM, проверка с другого компьютера и после перезагрузки VM. Виртуальной машины у пользователя пока нет. Инструкция подготовлена в `DEPLOY.md`.

## Поиск во время ввода и просмотренные фильмы

По дополнительному требованию пользователя добавлены живой поиск с задержкой 300 мс и личная отметка просмотра. Перед созданием и изменением отзыва API проверяет `Watched` для текущего пользователя; чужая отметка и переданный клиентом `is_watched=true` не открывают доступ. Удалить отметку при наличии собственного отзыва нельзя: сначала нужно удалить отзыв.

- Последний прогон: **20 из 20 API-тестов прошли**. Проверены запрет до просмотра, публикация после просмотра, изменение отзыва, личный статус в списке и карточке, повторная отметка, уникальность и удаление зависимых отметок вместе с фильмом.
- Сборки Django и React успешны, миграция `0002_watched` применена, незаписанных изменений моделей нет.
- До миграции сохранены контрольные суммы всех 13 существующих отзывов. После миграции все поля этих отзывов совпадают, к каждому добавлена соответствующая отметка просмотра.
- В браузере: со второй страницы каталога ввод «Мат» без кнопки нашёл один фильм и сбросил страницу; очистка вернула 15 фильмов. При вводе «Назад » пробел сохранился в поле, поиск сработал. В избранном ввод «Интер» без кнопки нашёл один фильм, очистка вернула три.
- На фильме без личной отметки форма отзыва отсутствует. После отметки появляется и сохраняется после перезагрузки страницы. Тестовый отзыв через форму опубликован с оценкой 8, снятие отметки стало недоступно.
- Созданный проверкой отзыв удалён. После этого отметка снята через интерфейс, форма снова закрылась. Чужие и ранее существовавшие отзывы не удалялись.
- Объяснение новых механизмов добавлено в `PROJECT.md`, описание API и поведения — в README. Скриншоты карточки и избранного обновлены.
