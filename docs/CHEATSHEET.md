# Короткая памятка перед защитой

## Запуск

- На Mac: **`Запустить VM.command`** → дождаться готовности → http://localhost:8084.
- Терминал Ubuntu: **`SSH в VM.command`**.
- Для другого устройства: адрес из окна запуска, одна Wi-Fi сеть.
- Рядом открыть код и `docs/demo-poster.png` для загрузки.

## Порядок показа

1. Назвать вариант и возможности: каталог, отзывы, избранное, роли.
2. В SSH показать Ubuntu, три контейнера, health.
3. Гость: поиск при вводе, фильтры, пагинация, карточка.
4. Администратор: создать **«Фильм для защиты 01»**, загрузить постер, изменить год.
5. Зарегистрировать нового обычного пользователя, войти.
6. На новом фильме: сначала нет формы отзыва → отметить просмотр → отзыв 8 → изменить на 10 → рейтинг обновился.
7. Добавить новый фильм в избранное → скачать Excel → открыть файл.
8. Другой пользователь: отдельное избранное, чужой отзыв без редактирования, нет добавления фильма.
9. Администратор: Excel с поиском; отмена удаления; затем удаление созданного для показа фильма.
10. Показать модели, классовую view, serializer, permissions, Docker Compose.
11. По просьбе: 22 теста, перезагрузка VM и сохранность данных.

## Команды в SSH-терминале Ubuntu

```bash
cat /etc/os-release
uname -m
cd ~/movie-catalog
docker compose ps
curl http://localhost:8084/health
docker compose logs --tail=20 app
```

По запросу преподавателя:

```bash
docker compose exec app python manage.py test --noinput
cat /proc/sys/kernel/random/boot_id
sudo reboot
```

После reboot снова открыть SSH, проверить новый boot_id, контейнеры, health и выбранный фильм.

## Шесть объяснений, которые нужно понимать

- Путь запроса: **React → nginx → Django → PostgreSQL → JSON → React**.
- **Модель** описывает данные и связи; **view** обрабатывает запрос; **serializer** проверяет поля и готовит JSON; **permission** проверяет доступ.
- **JWT** определяет вошедшего пользователя; сервер проверяет его подпись, срок и отзыв при выходе.
- **Средний рейтинг** вычисляется через ORM `Avg` при чтении; в Movie отдельного поля рейтинга нет.
- **Избранное и просмотр** принадлежат конкретному пользователю. Отзыв разрешён после личной отметки просмотра.
- **Тома** сохраняют PostgreSQL и постеры при перезапуске; **restart: unless-stopped** возвращает контейнеры после загрузки Docker.
