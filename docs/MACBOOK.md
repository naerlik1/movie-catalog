# Локальная работа на MacBook

Текущий проект находится в папке `Documents/ChatGPT/практика`. Здесь можно разрабатывать и показывать приложение с этого MacBook. Отдельную Ubuntu VM подготовим следующим этапом; она остаётся требованием задания.

## Запуск из Finder

Дважды нажмите **`Запустить.command`**. Откроется Terminal с ходом запуска. Когда Docker и три контейнера будут готовы, скрипт проверит `/health` и откроет **http://localhost:8084** в браузере. Окно Terminal можно закрыть после сообщения «Каталог готов»: контейнеры продолжат работать в фоне.

Скрипт использует Docker из PATH либо из `/Applications/Docker.app/Contents/Resources/bin/docker`. Поэтому не нужны Homebrew, системный Python, npm или отдельно установленная PostgreSQL.

При обычном повторном запуске образы берутся с диска, Docker Registry не запрашивается. Перед первым запуском на новой машине нужны интернет и первичная сборка. На этом Mac сборка и заполнение демо-данными уже выполнены.

## После изменения кода

Используйте **`Обновить сборку.command`**. Он пересоберёт образы, поднимет контейнеры и откроет приложение. Обычный `Запустить.command` предназначен для запуска готовой сборки, поэтому изменения исходников без пересборки в ней не появятся.

## Остановка

**`Остановить.command`** останавливает контейнеры. PostgreSQL и постеры остаются в именованных томах Docker. Следующий запуск откроет те же данные. Выход из аккаунта в браузере не останавливает сервер.

## Настройки и данные

- `.env` содержит локальный ключ Django и пароль БД. Существующий файл скрипт не меняет. Его нельзя заменить пустым шаблоном при работе с уже созданной базой.
- Данные БД находятся в томе `movie-catalog_pgdata`, постеры — в `movie-catalog_uploads`. Они не являются файлами внутри ZIP с исходниками.
- На чистой машине без этих томов скрипт может создать `.env` со случайными секретами. Если том БД уже есть, но `.env` отсутствует, скрипт попросит восстановить исходные настройки, вместо генерации другого пароля к существующей БД.
- Скрипт не сбрасывает базу и не запускает `seed_demo` повторно.
- Пароли тестовых аккаунтов находятся в README. JWT действует 24 часа; если он истёк, войдите заново.

## Запуск из Terminal при необходимости

```bash
cd ~/Documents/ChatGPT/практика
bash scripts/project.sh start
```

Для проверки запуска без открытия нового окна браузера:

```bash
bash scripts/project.sh start --no-browser
```

Команды для тестов и миграций из README можно выполнять через полный путь Docker:

```bash
/Applications/Docker.app/Contents/Resources/bin/docker compose exec app python manage.py test --noinput
```

Подробный сценарий защиты — порядок запуска, роли, действия в интерфейсе и ответы на вопросы по коду — подготовим после завершения проекта и настройки VM.
